![[加上偏置电压的 NMOS 晶体管.png]]
如上图，源极接地，栅极给电压 $V_{GS}$，漏极给电压 $V_{DS}$。沿着 x，沟道上的电压从栅极到源极线性减小到 0，于是在 $x$ 处有电压 $V(x)$。在这一点，栅极到沟道的电压就是 $V_{GS}-V(x)$。假设其大于阈值电压，于是有这一点的电荷为，
$$
Q_{i} ( x ) \,=\,-C_{o x} [ \, V_{G S}-V ( x )-V_{T} ]
$$
其中，$C_{ox}$ 为[[栅氧单位面积电容]]，
![[栅氧单位面积电容计算式]]
电流是载流子漂移速度 $v_{n}$ 和所存在电荷的积。$W$ 是垂直于电流方向上的沟道有效宽度。有，
$$
I_{D} \,=\,-\upsilon_{n} ( x ) Q_{i} ( x ) W
$$
>[! question]
>这里为什么只考虑了沟道宽度？
>因为反型层实际上非常薄，所以我们可以将其看作薄薄的一层电子来计算。

有电子漂移速度和场强的关系，
![[电子漂移速度]]

再将以上公式代入电流定义式，并沿着沟道有效长度 $L$ 积分可得，

$$
I_{D} \,=\, k_{n}^{\prime} \, \frac{W} {L} \Biggl[ ( V_{G S}-V_{T} ) V_{D S}-\frac{V_{D S}} {2}^{2} \Biggr] \,=\, k_{n} \Biggl[ ( V_{G S}-V_{T} ) V_{D S}-\frac{V_{D S}} {2}^{2} \Biggr]
$$
