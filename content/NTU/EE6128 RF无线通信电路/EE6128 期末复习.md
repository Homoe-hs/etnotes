# 基础知识

- 转置，即取共轭，将相位角的符号或虚数符号取反即可。
	- $S_{21}=2.5\angle 70^{\circ}$ 的转置 $S_{21}^{*}=2.5\angle -70^{\circ}$
	- $S_{21} = 1+j 5$ 的转置 $S_{21} = 1- j 5$
 - 极坐标乘法，即将幅值相乘，再将相位角相加
	 - $S_{11}=0.5\angle 180^{\circ}$，$S_{22}=0.8 \angle -100^{\circ}$，$S_{11}\times S_{22}=(0.5\times 0.8)\angle (180^{\circ}-100^{\circ})=0.4\angle 80^{\circ}$
	 - 源自复数的指数表示
		 - $z = r e^{j\theta}=r(\cos \theta + j\sin \theta)$
- 复数的绝对值，即取复数的实部或者极坐标的幅度。

- 稳定性
	- unconditionally stable：对所有无源信号源和负载阻抗有 $\lvert \Gamma_{in} \rvert<1$ 和 $\lvert \Gamma_{out} \rvert < 1$（ $\lvert \Gamma_{S} \rvert<1$ 和 $\lvert \Gamma_{L} \rvert < 1$）
	- potentially unstable：对部分无源信号源和负载阻抗有 $\lvert \Gamma_{in} \rvert<1$ 和 $\lvert \Gamma_{out} \rvert < 1$（ $\lvert \Gamma_{S} \rvert<1$ 和 $\lvert \Gamma_{L} \rvert < 1$）
- 稳定性检验
	- 对于单边器件而言（$S_{12} = 0$），当满足 $\lvert S_{11} \rvert < 1$ 和 $\lvert S_{22} \rvert<1$ 的时候，器件无条件稳定。
